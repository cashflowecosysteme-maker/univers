Réception des paiements

Dans le Worker Univers, ajoute un secret CLOSER_WEBHOOK_SECRET. Dans Systeme.io → Paramètres → Webhooks, utilise la même valeur dans « Clé secrète », cette URL et les événements « Nouvelle vente » et « Vente annulée ».

Seules les ventes issues d’un lien personnel de cet outil sont traitées. Le webhook Studio Prompt existant reste séparé.
